# Nexus 网页采集

1. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
2. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的本目录。
3. 在 Nexus 桌面版打开「网页采集」并生成配对码。在浏览器工具栏点开 Nexus 扩展，输入配对码。
4. 右键图片、视频、链接或网页，选择对应的 Nexus 采集操作。点开扩展可预览和筛选当前页媒体，勾选后批量采集，每批最多 30 项。

## 快捷操作

- 点击「拖拽采集」启用当前页工具，把图片拖到右下角采集区，或者按住 Alt 右键点击图片。按 Esc 退出。
- 截图支持可见区域、手动框选、元素的可见部分和整页。整页支持单方向滚动的网页，最多截取 8 屏。固定页眉等页面元素可能随滚动重复出现。
- 默认快捷键为 Alt+Shift+N 保存当前网页链接，Alt+Shift+S 截取当前可见区域。浏览器的扩展快捷键页面可修改按键。

公开 HTTPS 媒体直链进入 Nexus 采集箱。流媒体和浏览器临时视频地址会保存为页面链接。站点登录状态和 Cookie 随浏览器保留。桌面接收截图需要更新到支持截图的 Nexus 版本。
